# Support

## Getting Help

- **Usage questions**: Start with the [documentation guides](docs/index.md) —
  in particular [Getting Started](docs/getting-started.md),
  [Troubleshooting & FAQ](docs/troubleshooting.md), and the
  [Cookbook](docs/cookbook.md).
- **Something isn't working as documented**: Open a
  [bug report](.github/ISSUE_TEMPLATE/bug_report.yml). Please include a
  minimal trace JSON that reproduces the issue — traces are the primary input
  this project reasons about, so a repro trace is far more useful than a
  description.
- **You'd like a new capability**: Open a
  [feature request](.github/ISSUE_TEMPLATE/feature_request.yml).
- **General questions or discussion**: Use
  [GitHub Discussions](https://github.com/murkbyash/llm-reliability/discussions)
  if enabled on the repo, otherwise open an issue tagged `question`.

## Security Issues

Do **not** open a public issue for a security vulnerability. See
[SECURITY.md](SECURITY.md) for private disclosure instructions.

## Response Times

This is a community-maintained open source project without a dedicated
support team or SLA. Best-effort responses only — see
[SECURITY.md](SECURITY.md) for the (faster) security-specific SLA.

## Contributing

If you're able to fix or improve something yourself, see
[CONTRIBUTING.md](CONTRIBUTING.md) — pull requests are welcome.
